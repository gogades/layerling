## 開啟進階模式

有些設計在一個數值決定其他數值時會更簡單：蓋子總是比盒子小 0.4 公釐，孔與孔之間相隔同樣的壁厚，一個零件無論另一個移到哪裡都待在它旁邊。為此，進階模式加入了公式與變數。在 {{ui:editor.workspaceSettings}} 的 {{ui:workspace.appearance}} 分頁中開啟 {{ui:workspace.advancedMode}}。其他人完全不會遇到這些：在一般模式與簡易模式中，數值欄位、屬性面板與功能區都維持原樣。

使用了公式的設計在沒有進階模式時也能開啟。它會顯示公式最後得出的數值，並有一則提示說明它使用了公式，附帶 {{ui:advanced.switchOn}}。你在那裡修改的數值從此就是一般數字：它的公式會被移除，所以切換回進階模式永遠不會復原你的修改。

## 數值欄位中的公式

在進階模式中，屬性面板的每個數值欄位都接受公式。像寫算式一樣輸入：

| 寫法 | 意思 |
| --- | --- |
| `$wall * 2` | 變數表中變數 `wall` 的兩倍 |
| `$lid.size.width - 0.4` | 名為 `lid` 的實體寬度減 0.4 |
| `$lid.position.x + 30` | 在 `lid` 右側 30 |
| `$self.size.width / 2` | 這個實體本身寬度的一半 |
| `round($wall)`、`sqrt($a)`、`sin(30)`、`cos($angle)`、`pi` | 四捨五入（一半遠離零）、平方根、以度為單位的正弦與餘弦、圓周率 |

名稱以 `$` 開頭。大小寫沒有差別：`$Wall` 和 `$wall` 是同一個。數字使用設計顯示數值欄位時的單位；公式裡沒有單位。

由公式決定的數值欄位會被上色並標上 *fx*。點一下它，公式就會回來讓你修改。無法計算的公式——不存在的名稱、除以零、兩個互相依賴的公式——會讓欄位變成紅色，它的提示會說明原因。在此期間欄位保留最後的數值。在欄位中輸入一般數字會再次移除公式。工作區上的尺寸框也一樣：由公式決定的寬度、長度、高度或離開底板的高度會在框中顯示 *fx*，點一下框中打開的就是公式，前面的 *fx* 可打開公式編輯器。

## 給實體一個變數名稱

公式可以讀取任何有變數名稱的實體的任一欄位。在屬性面板頂端的 {{ui:formula.variableName}} 中給它一個名稱：字母、數字和 `_`，不能以數字開頭，也不能與其他實體或變數同名。它的欄位接著這樣稱呼：

| 欄位 | 在公式中 |
| --- | --- |
| 寬度、長度、高度、直徑 | `$name.size.width`、`.size.length`、`.size.height`、`.size.diameter`；圓形實體的寬度和長度就是它的直徑 |
| 位置 X、Y、Z | `$name.position.x`、`.position.y`、`.position.z` |
| 旋轉 X、Y、Z | `$name.rotation.x`、`.rotation.y`、`.rotation.z` |
| 旋轉點 X、Y、Z | `$name.pivot.x`、`.pivot.y`、`.pivot.z` |
| 錐度、扭轉與形狀本身的設定 | 依所屬分組，例如 `$name.taper.top_length`, `$name.twist.angle`, `$name.gear.teeth`；輸入 `$name.` 後公式編輯器會列出全部 |

重新命名實體會在所有使用它的公式中一併改名。已命名實體的副本——貼上、複製或插入的——不會保留名稱，因為兩個實體不能共用一個名稱；會有一則簡短訊息說明。

## 變數表

{{ui:variables.title}} 可從功能區中的按鈕或 [[Ctrl]]+[[Shift]]+[[V]] 開啟。每一列有名稱、數值或公式、其結果與簡短說明。{{ui:variables.add}} 新增一列；垃圾桶刪除一列。按下 [[Enter]] 或離開儲存格後修改即生效，[[Ctrl]]+[[Z]] 可以像復原其他步驟一樣復原它。無法計算的結果會顯示紅色標記；它的提示會說明原因。重新命名一列會在所有公式中一併改名。表格下方可以看到哪些實體有變數名稱。視窗可以拖曳標題移動，並拖曳右下角放大。

## 公式編輯器

較長的公式在公式編輯器中更容易撰寫：點一下由公式驅動的欄位開頭的 *fx*，或點一下任一欄位，再點其開頭出現的 *fx*。它會在你輸入時顯示結果，或說明為什麼沒有結果。輸入 `$` 後它會列出變數與已命名的實體，輸入 `$name.` 後列出該實體的欄位，每項都附上數值；用方向鍵和 [[Enter]] 或 [[Tab]] 選擇一項。之後 [[Enter]] 套用公式，[[Shift]]+[[Enter]] 換行讓長公式易讀，[[Esc]] 不做修改直接關閉編輯器。它可以拖曳標題移動。

## 當數值變動時

所有依賴於某個已變動數值的內容都會立即跟隨，作為歷程記錄中的一步：跟隨 `lid` 的實體會在 `lid` 變大時移動。有幾點值得了解：

- **拖曳帶公式的欄位**會保留公式並加上差值：再拖遠 5 公釐的 `$wall * 2` 會變成 `$wall * 2 + 5`。把一個實體和它跟隨的實體一起移動，它的公式不會改變。
- **鎖定的實體**不會跟隨它的公式；它的欄位會說明。
- **群組內的零件**在群組關閉時仍保留各自的公式和變數名稱，公式也可以讀取它們。當它們所依賴的值改變時，群組會在其餘部分之後稍晚重建，並算在同一個歷史步驟中。移動或拉伸群組時，差值會寫進其零件的公式，和拖曳時一樣。帶有自身圓角或倒角的群組不會重建；請用 {{ui:group.edit}} 開啟它來更新。
