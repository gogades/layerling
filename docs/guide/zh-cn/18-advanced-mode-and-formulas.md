## 开启高级模式

有些设计在一个数值决定其他数值时会更简单：盖子总比盒子小 0.4 毫米，孔与孔之间相隔同样的壁厚，一个零件无论另一个移到哪里都待在它旁边。为此，高级模式加入了公式和变量。在 {{ui:editor.workspaceSettings}} 的 {{ui:workspace.appearance}} 选项卡中打开 {{ui:workspace.advancedMode}}。其他人完全不会遇到这些：在普通模式和简单模式中，数值栏、属性面板和功能区都保持原样。

使用了公式的设计在没有高级模式时也能打开。它显示公式最后得出的数值，并有一条提示说明它使用了公式，附带 {{ui:advanced.switchOn}}。你在那里修改的数值从此就是普通数字：它的公式会被去掉，所以切换回高级模式永远不会撤销你的修改。

## 数值栏中的公式

在高级模式中，属性面板的每个数值栏都接受公式。像写算式一样输入：

| 写法 | 含义 |
| --- | --- |
| `$wall * 2` | 变量表中变量 `wall` 的两倍 |
| `$lid.size.width - 0.4` | 名为 `lid` 的实体的宽度减 0.4 |
| `$lid.position.x + 30` | 在 `lid` 右侧 30 |
| `$self.size.width / 2` | 这个实体自身宽度的一半 |
| `round($wall)`、`sqrt($a)`、`sin(30)`、`cos($angle)`、`pi` | 四舍五入（一半远离零）、平方根、以度为单位的正弦和余弦、圆周率 |

名称以 `$` 开头。大小写没有区别：`$Wall` 和 `$wall` 是同一个。数字使用设计显示数值栏时的单位；公式里没有单位。

由公式决定的数值栏会被着色并标上 *fx*。点击它，公式就会回来供你修改。无法计算的公式——不存在的名称、除以零、两个相互依赖的公式——会把数值栏变成红色，它的提示会说明原因。在此期间数值栏保留最后的数值。在数值栏中输入普通数字会再次去掉公式。

## 给实体一个变量名

公式可以读取任何有变量名的实体的任意数值栏。在属性面板顶部的 {{ui:formula.variableName}} 中给它一个名字：字母、数字和 `_`，不能以数字开头，也不能与其他实体或变量同名。它的数值栏随后这样称呼：

| 数值栏 | 在公式中 |
| --- | --- |
| 宽度、长度、高度、直径 | `$name.size.width`、`.size.length`、`.size.height`、`.size.diameter`；圆形实体的宽度和长度就是它的直径 |
| 位置 X、Y、Z | `$name.position.x`、`.position.y`、`.position.z` |
| 旋转 X、Y、Z | `$name.rotation.x`、`.rotation.y`、`.rotation.z` |
| 旋转点 X、Y、Z | `$name.pivot.x`、`.pivot.y`、`.pivot.z` |
| 锥度、扭转和形状自身的设置 | 按所属分组，例如 `$name.taper.top_length`, `$name.twist.angle`, `$name.gear.teeth`；输入 `$name.` 后公式编辑器会列出全部 |

重命名实体会在所有使用它的公式中同时改名。已命名实体的副本——粘贴、复制或插入的——不会保留名称，因为两个实体不能共用一个名称；会有一条简短消息说明。

## 变量表

{{ui:variables.title}} 可通过功能区中的按钮或 [[Ctrl]]+[[Shift]]+[[V]] 打开。每一行有名称、数值或公式、其结果和简短说明。{{ui:variables.add}} 添加一行；垃圾桶删除一行。按下 [[Enter]] 或离开单元格后修改即生效，[[Ctrl]]+[[Z]] 可以像撤销其他步骤一样撤销它。无法计算的结果会显示红色标记；它的提示会说明原因。重命名一行会在所有公式中同时改名。表格下方可以看到哪些实体有变量名。窗口可以拖动标题移动，并拖动右下角放大。

## 公式编辑器

较长的公式在公式编辑器中更容易编写：点击一个数值栏，然后点击它末端的小按钮 *fx*。它会在你输入时显示结果，或者说明为什么没有结果。输入 `$` 后它会列出变量和已命名的实体，输入 `$name.` 后列出该实体的数值栏，每项都带着数值；用方向键和 [[Enter]] 或 [[Tab]] 选择一项。之后 [[Enter]] 应用公式，[[Shift]]+[[Enter]] 换行以便长公式易读，[[Esc]] 不做修改直接关闭编辑器。它可以拖动标题移动。

## 当数值变化时

所有依赖于某个已改变数值的内容都会立即跟随，作为历史记录中的一步：跟随 `lid` 的实体会在 `lid` 变大时移动。有几点值得了解：

- **拖动带公式的数值栏**会保留公式并加上差值：再拖远 5 毫米的 `$wall * 2` 会变成 `$wall * 2 + 5`。把一个实体和它跟随的实体一起移动，它的公式不会改变。
- **锁定的实体**不会跟随它的公式；它的数值栏会说明。
- **组内的零件**在组关闭时仍保留各自的公式和变量名，公式也可以读取它们。当它们所依赖的值改变时，组会在其余部分之后稍晚重建，并算在同一个历史步骤中。移动或拉伸组时，差值会写进其零件的公式，和拖动时一样。带有自身圆角或倒角的组不会重建；请用 {{ui:group.edit}} 打开它来更新。
